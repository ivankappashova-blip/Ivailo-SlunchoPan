## ✍️ Как се пише пожелание

1. Отвори `messages.js`.
2. Намери годината, напр. `2026: { bg: "", en: "" },`
3. Напиши текста между кавичките:

```js
2026: {
  bg: "Честит 8-ми рожден ден, Ивайло! Обичам те!",
  en: "Happy 8th birthday, Ivaylo! I love you!"
},
```

4. Запази файла → качи го отново в GitHub. Готово!

Празните години (`bg: "", en: ""`) остават **заключени** 🔒.
Годината се отключва **само** когато са изпълнени ДВЕ неща:
– дошъл е 26 септември на съответната година, И
– има написан текст.

> Забравил си да напишеш пожелание, но датата е дошла? Не е проблем —
> отваря се лесно съобщение „Тук скоро ще има пожелание“. Напиши текста
> и го качи, и той се появява веднага.

## ➕ Още години („до безкрай“)

Годините стигат **до 100-годишнината** (2026 – 2118), а списъкът се строи сам
от едно число. В `messages.js`, в `CONFIG`:

```js
ageLimit: 100,   // смени на 120, 150, 200 ... колкото искаш
```

Ако вдигнеш `ageLimit`, просто добави още редове в `WISHES`
(или копирай последния ред и смени годината). Ако искаш да е
наистина неограничено, сложи голямо число, напр. `ageLimit: 300`.

## 🚀 Публикуване в GitHub Pages

1. Нов **публичен** repo, напр. `slanchopan`.
2. Качи **всички** файлове в основната директория (root), не в подпапка.
3. **Settings → Pages**.
4. Source: **Deploy from a branch** · Branch: **main** · Folder: **/ (root)** → **Save**.
5. След 1–2 минути сайтът е на:
   `https://ТВОЕТО_ИМЕ.github.io/slanchopan/`

Прати линка на Ивайло. 🎂
